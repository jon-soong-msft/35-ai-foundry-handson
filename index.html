Lab 1 scenario — acl-remedy-advisor

You build one agent: an Australian Consumer Law Remedy Advisor that helps a retailer decide whether a customer is entitled to a repair, replacement, or refund. You give it instructions, add web search and a code tool, ground it in policy documents, wire in a custom MCP tool, evaluate it, monitor it, and publish it — each module building on the last.

Labs 2 & 3 scenario — Meridian Commercial Bank

A commercial loan underwriting case: an application flows through a sequential intake pipeline, a group-chat / Magentic credit committee (Risk + Fraud/AML + Compliance, moderated by a Chair), and a policy-gated human-in-the-loop Senior Underwriter sign-off. Lab 2 builds it visually in the portal Workflows designer; Lab 3 re-implements the exact same case in Python — the designer-to-code path Microsoft is steering teams toward.
