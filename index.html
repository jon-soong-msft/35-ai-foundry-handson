The scenario — acl-remedy-advisor

Across the modules you build one agent: an Australian Consumer Law Remedy Advisor that helps a retailer decide whether a customer is entitled to a repair, replacement, or refund. You give it instructions, add web search and a code tool, ground it in policy documents, wire in a custom MCP tool, evaluate it, monitor it, and publish it — each module building on the last.
